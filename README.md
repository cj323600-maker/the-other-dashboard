# 전략기획 ERP

코오롱오토옥션 전략기획팀 보고 및 대시보드 통합 포털 (GitHub Pages)

## 메뉴와 폴더

| 메뉴 | 폴더 |
|---|---|
| 일간보고 | `daily/` |
| 주간보고 | `weekly/` |
| 월간보고 | `monthly/` |
| 회원사 낙찰추이 | `member/` |
| 출품 및 낙찰 추이 | `trend/` |

## 파일명 규칙

`날짜_제목.확장자`

- 일 단위: `2026-11-10_일간보고.html` (`20261110_일간보고.html`도 인식)
- 월 단위: `2026-10_월간보고.html`
- 날짜가 없으면 목록 하단 "날짜 미지정"에 표시
- 최신순 정렬, 등록일 기준 3일 이내 파일은 NEW 표시
- html/pdf/이미지는 바로 열람, xlsx 등은 다운로드

## 반영 방식

`main` 브랜치에 파일을 올리면 홈페이지 목록에 자동 반영됩니다 (목록은 브라우저에서 5분간 캐시).
